关于 Yu

一个窗口，装下所有想法

Yu 是一款温和、现代的 Markdown 编辑器。每个文件都作为标签页在同一个窗口里打开，让写作回到安静、专注的画布。

✦

所见即所得。 写下 Markdown，立即看到清晰、舒服的最终排版。

它能做什么

  • 标签页多文件同窗，⌘Tab 快速切换
  • 文件树原地新建、重命名与整理文档
  • 漂亮排版代码高亮、表格、数学公式和图片

代码与公式

行内代码 const app = createApp() 和块级代码都保持清晰的阅读节奏：

func openDocument(_ url: URL) {
  let document = workspace.open(url)
  editor.present(document)
}
好工具应该让内容成为主角，而不是让界面抢走注意力。
