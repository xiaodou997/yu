# Windows 图片交互与样式迭代（2026-10-03）

## 设计取舍

参考用户提供的 Typora 图片操作截图和紧凑顶部菜单截图，直接修改 Windows 程序并实际启动验证，不是只做效果稿。

- 单击图片保持渲染，显示细蓝色描边和一条可编辑的源码栏。
- 源码栏只保留“图片 / 源码 / 替换 / 当前比例 / 更多”，不再堆放源码、Alt、地址和多行原生输入框。
- 初版源码栏停靠在正文上方；按用户后续要求，现改为选中图片正上方浮动，间隔 8 逻辑像素，随图片滚动。选中 / 退出不改变正文排版，图片完全离屏时隐藏；浮层遮挡限制见最后一节。
- Enter 或失焦提交当前图片源码；Esc 退出选中，不提交未完成草稿。共享编辑器验证当前这一张图片的完整表达，拒绝附加图片 / 正文，避免误改其他内容。
- 双击保留“图片属性”高级入口，可精确编辑地址、Alt、宽高和比例锁；右键仍可进入普通 Markdown 源码编辑。
- 单击图片本身不立刻弹选择器，避免选择 / 双击被弹窗打断；“替换”是明确的选文件入口。
- 窄窗口收起替换和比例按钮，完整操作仍在更多 / 右键菜单中，不展开三行大面板。
- 顶部菜单从 40 收紧到 32 逻辑像素，缩短按钮间距、降低文字视觉重量、保留圆角悬停，标题栏与菜单使用统一色调。
- 没有强行把菜单并入自绘标题栏。Windows 原生标题栏、系统窗口按钮仍保留，没有仿造 macOS 窗口按钮。

## 图片操作

右键保留替换、打开、Explorer 定位、复制位图、复制地址、大小、属性、编辑源码；新增“复制图片到…”，不移动原文件，不改变文档引用。

尺寸菜单提供 25%、33%、50%、67%、80%、100%、150%、200%、原始大小、适应正文宽度；按缩小 / 原比例 / 放大分组，标示当前显示比例。远程条目不提供本地专属操作和文件导出。

参考图中的重命名 / 移动暂未加入：需要磁盘覆盖保护及与文档 Undo 的一致性，不添加不可用的假菜单。

图片选择改用系统原生 Explorer 风格 GetOpenFileNameW，绕开之前此环境下崩溃的图片 IFileOpenDialog.Show 链路；文件导出使用 GetSaveFileNameW，包含覆盖确认和不改变当前工作目录。

实测另发现替换后原生按钮仍持有焦点，Ctrl+Z 不走文档历史；修复后焦点交还编辑器，两入口撤销 / 重做均精确恢复。文件导出最初因完整路径被当作默认文件名出现 0x3002，现分别传递文件名、初始文件夹和扩展名，已重测通过。

源码永久修改使用共享 EditorDocument 的 revision、精确范围、Transaction 和 History，不在 Windows 层另写解析器；在完整文档上下文验证候选，保留引用定义、邻近图片和正文。新增两项测试覆盖范围、无效输入、引用上下文及历史回放。

保存及新建 / 打开 / 关闭文档前也先提交源码栏草稿，防止原生输入框尚未失焦时保存旧内容或关闭丢失修改；无效源码返回错误并中止切换。实窗使用中文 Alt 草稿，不按 Enter 直接 Ctrl+S，文件内容、一次 Undo / Redo 和重开后的源码全部精确一致；另验证直接关闭会显示保存确认并正确写入草稿。

修复前和脚本校准的失败记录保留。以 source-result、replace-final、right-replace-final、export-final 等最终结果为准，不把错误截图或未完成测试写成通过。

## 后续：源码栏移到图片上方

依据用户后续位置反馈，源码栏改以真实图片矩形为锚点，不再停靠文档顶部。最大宽度 640 逻辑像素；默认与图片左边对齐，靠近右边界时向左避让，靠近顶部时在正文区域边缘限位。历史截图 40 / 41 是此前停靠版本；当前定位截图为 `49-image-anchor-final.png`。

### 通过

- 定位几何测试 4 项通过，包括 96 / 120 / 144 / 192 DPI 的间距、滚动位移及边界限位；编译、Clippy、格式检查通过。
- 真实窗口 DPI 192：工具条底边距图片顶边 16 物理像素；一次滚动后两者同时上移 96 像素，完全离屏时所有图片控件隐藏。
- 源码栏 Esc 取消草稿、重新选中恢复原源码、文档文件未变化，见 `image-anchor-result.json`。
- 窄窗口选中图片时工具条收起辅助按钮；最大化 / 还原实际操作。首次窄窗口截图未选中，不作为选中定位通过证据；随后已实际重新选中验证。

### 问题

- 当前实现是浮层，不是为源码栏重排正文的内联占位。在预览文档第一张图片处，图片前的段落与图片之间留白不足，工具条会覆盖前一行文字。复现：打开 `artifacts/image-ux-20261003/preview.md`，200% Windows 缩放、2100×1700 窗口，单击 `assets/yu-mark.png` 图片。预期是不遮挡文字；实际覆盖“单击图片查看源码，双击调整属性。编辑不必打断阅读。”所在行。截图 `49-image-anchor-final.png`。定位请求已落实，但不能将正文无遮挡记为通过；完全消除覆盖需要进一步引入临时布局占位。
