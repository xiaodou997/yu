# ADR 0004：采用 Apache License 2.0

- 状态：Accepted
- 日期：2026-08-09

## 决策

Yu Editor 的项目代码和正式仓库文档统一使用 Apache License 2.0。Cargo package 使用 SPDX
标识 `Apache-2.0`，仓库根目录保留完整 `LICENSE` 文本。

## 理由

- 允许个人、企业和开源项目使用、修改、再分发与商业集成；
- 包含明确的贡献者专利授权和专利诉讼终止条款；
- 与 Rust 及跨平台基础设施生态中的常见许可证容易组合；
- 不要求使用 Yu 的独立应用或更大组合作品必须开源。

## 结果

- 分发源码或二进制时必须提供许可证副本；
- 修改并分发的文件需要带有显著的修改说明；
- 必须保留适用的版权、专利、商标和归属声明；
- 如果未来加入 `NOTICE`，再分发者也需要保留其中适用的归属内容；
- Apache-2.0 不提供商标使用权，也不为软件提供担保。
