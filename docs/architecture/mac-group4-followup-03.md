## 4. 新的像素门禁

`--resource-audit --stress-seconds … --reopen` 在冷重开后追加 `Checks.restored_preview()`：仅接受固定的 `Stress restored / $x^2$ / TAIL` 文档，读取相邻标题与TAIL的原生屏幕范围，在两者之间的公式专用空隙采样。期间不点击公式、不修改源码、不重发粘贴、不滚动或缩放窗口。

原始公式源码区间可折叠到一像素光标，不能直接把该区间矩形当成公式的可见边界。首版观察器曾使用这种矩形，已纠正；失败截图仍保留。最终观察器使用相邻普通文字定位空隙，保存整窗、裁剪区域、对比像素数量及几何记录，最多三次有界观察；持续空白会失败。

门禁只判断固定区域不是纯背景，并不能证明任意公式的数学内容都正确，也不能代替截图复核。Pillow仅为测试工具依赖，未添加到产品运行时。六项新增单元测试覆盖浅深色空白、有效对比、忽略范围外标题、越界拒绝、非有限／空范围和错误语料拒绝。
