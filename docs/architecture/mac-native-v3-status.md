## 已接入的链路

- Mac 段落由 CoreText 一次断行和塑形，返回行盒、基线、字形、双向文字边界与内联对象位置；Mac 不再走 Rust 的第二轮文字断行和双向重排。
- 字形回放持有 CoreText 实际选中的字体，使用原生字体哈希及相等性判断区分描述符、字号和变体。彩色 emoji 使用 RGBA 图集与 CGContext 缩放；1×/2× 实际墨迹大小有契约测试。删除字体适配层重复持有的图集。
- 修复 Metal 圆角矩形 uniform 的 CPU/GPU 布局不一致，并用真实 GPU 像素验证颜色。原实现 72 字节，Metal 要求 80 字节。
- 源码、语法树和搜索结果快照共享底层存储。新增 `EditorState` 与独立 `LayoutContext`：后台只准备布局上下文，不再构造 `EditorDocument`、可变文本缓冲区或空的撤销历史，也不再重复解析 Markdown 或扫描搜索结果。已测段落缓存随快照发布。
- 语法树的叶节点决定正常文档的排版块边界，引用和列表保留容器层级。修复引用列表、被拆开的 Setext 标题，以及跨空行的缩进代码块。
- 修复替换文档后搜索结果仍指向旧源码的偏移；缓存保留校验改用块索引查询，移除逐缓存项扫描全文块列表的路径。
- 源码分隔空行通过统一投影隐藏，活动空段落保留光标行；中文预编辑与提交共享段落位置。高度索引内部使用双精度，避免零高度块附近出现顺序倒置。
- Rust 与 Swift 使用同一份阅读列参数，修复绘制、输入定位与滚动留白的原点不一致。
- Mac 输入宿主已替换为 `NSView + NSTextInputClient`，删除 TextKit 文本存储、布局管理器和文本容器。输入、撤销、剪贴板、多选区仍回到 Rust 会话。
- 原生侧栏合并为“文件 / 大纲”，默认 240pt；删除独立图标栏、大品牌区域和浮动工具栏。标题居中，侧栏与状态区使用明确的主题背景色。查找改为顶部紧凑栏，状态区收起 Revision 等诊断。
- Github / Night 分别接入字体、字号、行高、标题粗细、段落间距和阅读列宽；主题及段落方向进入布局缓存键。CoreText 基线使用实际字体度量，显式行高不再被字体 ascent/descent 撑大。
- 接入文件侧栏和多文档窗口；现有表格、任务框、搜索、大纲、外部修改和保存检查继续保留。
- 提供 `--release --universal` 构建；Objective-C 桥接层显式使用 Cargo 的目标架构。CI 增加双架构构建。

## 已落地：统一已发布几何

- 新增不可变 `LayoutSnapshot`，绑定文档身份、源码版本、投影状态、布局参数和资源几何版本，持有已定位的共享段落。帧构建器的字形栅格化、场景装配、原生点击/光标/预编辑和表格查询读取同一份几何；不再向宿主公开另一份独立的测量缓存结果。
- 真实窗口发现并修复输入宿主宽度 1542pt、滚动视口宽度 642pt 的分叉：普通 `NSView` 不再沿用旧文本视图的自动宽度假设，阅读列布局显式同步宿主宽度。错误宽度会让几何查询重置已测量的高度，导致大纲跳转和输入位置错误；窗口及截图矩阵现在检查两者一致。
- 修复正文后续段落的光标遗漏文档偏移，以及代码块内边距重复或遗漏的问题；标题和表格光标使用实际文字行高。相邻段落的共同边界由后一段接收点击。
- 搜索高亮和重复几何查询复用快照，不重新塑形活动标题。已加载图片的尺寸发生变化时也会更新快照与后续段落位置，旧快照保持不可变。
- 取消检查覆盖普通段落、局部语法显隐和输入法预编辑；取消的准备任务不发布半成品几何。源码版本或资源几何改变后，旧结果不能重新被采纳。
- 新增真实窗口中的 `firstRect` 检查，验证后续段落的文档坐标、阅读列偏移和屏幕坐标只转换一次。这不等同于测量外部输入法候选面板的实际位置。

## 已落地：容器边界与列表语义

- `PresentationTree` 新增有序叶节点索引、列表起始编号、列表项显示编号和结构指纹。结构指纹不包含字节位置或无关段落内容；块的装饰、排版及高度缓存以它识别祖先容器和编号变化。
- `LayoutSnapshot` 发布引用、列表、列表项的已测量容器边界，并显式标注是否只覆盖容器的一部分。引用竖线沿容器延伸，覆盖内部段间距，结束于最后一段正文；列表内引用的竖线随祖先缩进。删除逐段生成引用竖线的旧几何方法。
- 间距沿相邻叶节点到共同容器的两条路径折叠。紧凑列表进出嵌套层级时不增加段落空隙；独立列表、宽松列表和引用内段落保留各自间距，不再凭相邻 `BlockKind` 都是列表项就清零。
- 有序列表按起始编号递增呈现，重复 `1.` 的源码不会被改写。修改起始编号、插入前面的列表项及撤销/重做都会更新后续显示；无关前缀插入仍复用段落排版。编号在构建呈现树时确定，不逐项扫描整张列表。
- 引用与列表的组合顺序决定项目符号位置；显式引用续行前的容器空格通过统一投影隐藏，防止重复缩进。段落缩进与容器边框共用主题中的几何参数。
- 实际截图发现引用列表尾部仅含 `>` 的分隔行被误当作段落，额外产生行高与间距；已修正块分类，并验证该行仅在光标进入时保留编辑高度。容器末端取最后一个语义内容节点，避免把尾部标记或外部间距算进容器。
- 新增 `Fixtures/native-containers.md` 作为组合回归语料。该轮仍未完成表格和图片在容器内的全部布局，也未完成布局协调器及 Typora 正式差异验收。
