## 本批修复

整文档输出先计算长度再分配：comrak 输出使用有界 sink，重复目录展开、槽替换（含末段字面文本）、文末注和最终 HTML 拼接均在适用分配前检查，使用 checked arithmetic 和受限容量增长。没有自造第二个 Markdown 解析器。

SVG 的字节/节点超限改为 fatal，不能再通过普通警告确认绕过限额；格式错误或主动用户内容仍按既定规则保留可读诊断。任务准备截止时刻改在任务创建时固定，解析前后使用同一检查，避免解析结束后才开始计算准备预算。未更换生产渲染后端。
