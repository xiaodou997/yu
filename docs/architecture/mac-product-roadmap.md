## 第三组：写作功能与图片流程

两版规划没有两个不同的“第三组目标”：第二版强调图片和结构化内容，却没有明确保留专注模式、打字机模式和拼写检查，并将设置移入交付。统一版合并这些遗漏；基础设置随写作功能落地，发行机制留在第六组。

### 3A 图片完整流程（优先）

现有 Rust 资源层具备相对文档路径解析、加载/失败状态和图片几何；Mac 输入宿主当前粘贴入口处理 Markdown、HTML、TSV 和文字，未接入图片文件/位图的完整导入流程，也未找到原生图片拖放与尺寸编辑入口。已有渲染能力不等于图片产品功能完成。

- 提供图片插入菜单、本地文件拖放、剪贴板位图粘贴；Markdown 修改统一走 Rust 事务与撤销。
- 明确资源复制/引用策略、相对路径、同名文件、中文/空格路径和未命名文档首次保存规则；不覆盖原图片。
- 衔接另存为、失败重试、加载中与缺失图片提示；避免文档保存成功但资源引用失效。
- 提供替代文字、路径和尺寸编辑，锁定纵横比；确定可保存的尺寸语法，不能只在当前窗口内有效。
- 覆盖撤销/重做、保存重开、窗口缩放、资源尺寸异步变化后的点击与光标几何。资源文件的保留/清理策略应避免删除仍被其他文档引用的图片。

### 3B 表格与结构化内容收尾

现有 `DocumentTextView.makeTableMenu` 已提供增删行列和列对齐；Tab/Shift-Tab、末格新增行、矩形复制粘贴、列宽拖动及连续撤销已在第二组验收，不重复开发。

- 补齐菜单/右键实际操作的组合验收：增删行列、对齐、边界单元格、引用内表格、撤销/重做与保存重开。
- 按缺陷补入口或交互，不重新构建已经通过的表格内核。

### 3C 写作模式与拼写检查

代码核查尚未发现专注模式、打字机模式或 NSSpellChecker 接线。

- 专注模式：突出当前段落、弱化其他正文，维持可读性；只改变呈现，不改源码和编辑历史。
- 打字机模式：输入时保持活动行处于阅读区目标位置；兼容手动滚动、文档首尾、缩放和输入法候选框，避免抢滚动或跳动。
- 原生拼写检查：接入系统检查与建议菜单；诊断区间映射到源码，替换走 Rust 事务；避开代码、URL、语法标记和正在组词的文字。按系统提供的语言能力工作，不把中文语病检查列为承诺。

### 3D 基础设置

当前主题和自动保存已有菜单/UserDefaults 设置，尚无集中设置窗口。建立原生设置窗口与统一状态，复用现有配置。

- 正文主题、字号/行宽，专注与打字机模式、拼写开关。
- 图片资源位置/复制策略、自动保存偏好。
- 验证多窗口同步、重启保留和恢复默认；只暴露已有功能，不放占位选项。

## 第三组完成条件

每个子项均有原生入口、可撤销的编辑行为（适用时）、保存重开检查及失败处理；新功能不得重排未编辑源码。浅深色、窄宽窗口、中文输入和缩放组合验证通过后结项。真实系统事件、产品内自检与人工操作分别记录；不将部分通过标为整组完成。

本轮仅核对并统一范围，第三组尚未开始实现。建议按 3A → 3B → 3C → 3D 推进，设置随对应能力逐步接线。
