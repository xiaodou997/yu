## 第三组：写作功能与图片流程

两版规划没有两个不同的“第三组目标”：第二版强调图片和结构化内容，却没有明确保留专注模式、打字机模式和拼写检查，并将设置移入交付。统一版合并这些遗漏；基础设置随写作功能落地，发行机制留在第六组。

### 3A 图片完整流程（优先）

已接入图片插入菜单、文件拖放和位图粘贴入口，以及复制/引用策略、Unicode 路径和另存为资源复制。位图粘贴、原文件引用、撤销与保存重开的浅深色自动化已有记录；真实文件选择框插入、取消、未命名文档首次保存成功/取消的浅深色实窗验收已通过，真实跨进程文件拖放的浅深色检查也已通过（插入、Esc 取消、损坏批次、撤销及保存重开）；未命名文档拖放与首次保存的取消/确认组合也已通过浅深色实窗检查。原生图片属性 sheet、宽高和纵横比锁定已接通，支持读取与修改可读的本地路径；事务、尺寸几何和原生控件已有定向验证，浅深色文件菜单属性编辑、撤销与保存重开已通过真实事件检查；图片异步恢复后的窄窗口/125%缩放/真实拼音组合已通过浅深色实窗检查，详见写作验收第二十四轮。

- 提供图片插入菜单、本地文件拖放、剪贴板位图粘贴；Markdown 修改统一走 Rust 事务与撤销。
- 明确资源复制/引用策略、相对路径、同名文件、中文/空格路径和未命名文档首次保存规则；不覆盖原图片。
- 衔接另存为、失败重试、加载中与缺失图片提示；避免文档保存成功但资源引用失效。
- 提供替代文字、路径和尺寸编辑，锁定纵横比；确定可保存的尺寸语法，不能只在当前窗口内有效。
- 覆盖撤销/重做、保存重开、窗口缩放、资源尺寸异步变化后的点击与光标几何。资源文件的保留/清理策略应避免删除仍被其他文档引用的图片。

图片另存为现允许保留原本缺失且目标仍缺失的引用，并支持解析到同一资源的父级相对路径；冲突仍拒绝。图片加载状态和手动重试已接入右键菜单，自动重试耗尽后停止刷新，真实 ImageIO 恢复、原生菜单动作自检及浅深色真实右键重试/属性面板/保存重开通过。非表格位置不再显示无关的禁用表格命令。不同资源目录的前导父级引用（如 `../shared/图.png`）已支持复制到新文档对应的兄弟目录，保留源码和撤销历史；存储级测试及浅深色真实 Save As 面板（取消、确认、撤销/重做、保存重开）通过。图片恢复后的几何组合已通过；最终综合回归已通过。

### 3B 表格与结构化内容收尾

已取得普通/引用表格的浅深色十项菜单命令、右键命中及对齐、首尾列连续结构修改、整串撤销重做与 BOM/CRLF 保存重开记录。最后一列删除会移除整表，且可撤销；表头不能按正文行删除。实窗诊断确认过一次菜单关闭后延迟派发：第二次源码观察约 0.735 秒后成功，期间未重发动作；测试现等待目标状态，超时仍失败。此前还出现过前台丢失及外部输入，不将所有历史失败武断归为同一原因。

现有 `DocumentTextView.makeTableMenu` 已提供增删行列和列对齐；Tab/Shift-Tab、末格新增行、矩形复制粘贴、列宽拖动及连续撤销已在第二组验收，不重复开发。

- 基础菜单/右键组合及边界行为已有本机验收；最终构建的中文输入、窄宽窗口及缩放组合回归已通过。
- 按缺陷补入口或交互，不重新构建已经通过的表格内核。

### 3C 写作模式与拼写检查

专注、打字机和自动拼写检查均已接入。真实拼音提交/取消、候选框定位、手动滚动、文档中部/末尾及125%缩放的浅深色组合已有通过记录；约1MiB文本、超长单词、预编辑暂停与旧revision结果拒绝通过原生契约测试。原生右键纠错、撤销与保存重开已有实窗记录。最终构建的浅深色组合回归已通过。

- 专注模式：突出当前段落、弱化其他正文，维持可读性；只改变呈现，不改源码和编辑历史。
- 打字机模式：输入时保持活动行处于阅读区目标位置；兼容手动滚动、文档首尾、缩放和输入法候选框，避免抢滚动或跳动。
- 原生拼写检查：接入系统检查与建议菜单；诊断区间映射到源码，替换走 Rust 事务；避开代码、URL、语法标记和正在组词的文字。按系统提供的语言能力工作，不把中文语病检查列为承诺。

### 3D 基础设置

已建立原生设置窗口，接入主题、字号、行宽、自动保存、图片目录和复制/引用策略。字号/行宽复用共享布局参数，已有/新建原生文档宿主同步及不改源码的自检通过；跨进程保留、恢复默认及浅深色窗口检查已有通过记录。专注/打字机及拼写开关均已接入；三个实际窗口的字号/行宽/模式/拼写设置、图片目录及复制/引用策略、独立撤销与恢复默认已通过浅深色实窗验证。三个窗口的 Github/Night/Yu 切换与自动保存关闭/开启/再次关闭已取得真实行为记录；并修复了正文主题与系统外观不一致时的标题栏、字数和大纲文字对比问题。最终构建的浅色主题复查五组通过，Github/Night/Yu 截图已检查，标题、字数与大纲均可读；完整组合回归已通过。

- 正文主题、字号/行宽，专注与打字机模式、拼写开关。
- 图片资源位置/复制策略、自动保存偏好。
- 验证多窗口同步、重启保留和恢复默认；只暴露已有功能，不放占位选项。

## 第三组完成条件

每个子项均有原生入口、可撤销的编辑行为（适用时）、保存重开检查及失败处理；新功能不得重排未编辑源码。浅深色、窄宽窗口、中文输入和缩放组合验证通过后结项。真实系统事件、产品内自检与人工操作分别记录；不将部分通过标为整组完成。

第三组实现及本机 macOS 27 验收已完成，逐项映射和最终记录见 [写作功能验收记录](mac-writing-experience.md)。最终同哈希十套实窗测试共94组通过，Rust测试1102项通过、4项忽略，18项原生自检通过。实际最大窗口1290×841pt，未宣称1600×1000、macOS 26实机或性能预算通过。下一组为公式、图表与扩展语法；发布范围仍按第六组跟进。
