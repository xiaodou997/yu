## 范围与表示

目标是原 Markdown 表格中已经存在行内公式，向其他单元格粘贴合并表格时，转换后的原生 HTML 表格仍保留可恢复、可编辑、可保存的公式。不是第五组导出功能。

公式保留为有限 HTML 的源码叶子，例如：

```html
<span data-math-style="inline">a&lt;b &amp; c</span>
```

`source` 指向完整元素的原文范围，`content` 指向正文的原文范围；两者都是当前文档的 UTF-8 字节坐标。送给既有 `EmbeddedKind::Math` 组件的 TeX 在读取时仅解码一次 HTML 实体，以上内容为 `a<b & c`，不使用图片替代公式，也不把解码后字符串的偏移冒充文档偏移。

转换计划逐单元格对齐原语法树中的 `InlineMath` 和转换后的公式叶子，用原始 TeX 回填经过 HTML 文本转义的正文。数量、归属或语法不一致即拒绝，不能只比较整张表的公式总数。这样保留反斜杠、转义竖线、字面实体文本以及未选中单元格的公式，不依赖转换器对 TeX 的字符串归一化。

原生投影将非活动公式交给现有公式组件。HTML 表格中的公式点击落在正文两端，不落在隐藏的 `<span>` 外；获得焦点时只显示可编辑正文。字符/实体删除保留身份标签，删除最后一个字符可保留空公式；完整选择公式删除时则连同标签删除一次。样式和链接仍由外围 HTML 节点持有。

## 明确边界

仅支持本批已对齐的行内美元公式和合法、纯文本正文的 `span data-math-style="inline"`。不全面开放 `data-*` 属性；重复属性、其他 math-style 值、自闭合、嵌套标签/注释、含换行的公式正文等仍拒绝原生表格转换或结构粘贴。渲染器能否理解某个 TeX 命令仍由既有公式诊断机制处理，不等于 HTML 结构是否合法。

脚注转换继续拒绝，不能把引用降级成普通上标。任意多光标不被推断成表格矩形。跨 `<thead>/<tbody>`、跨多个 `<tbody>` 的原有限制不变，不拆散合并单元格来冒充支持。本批不新增块公式语法、跨行组规则、导出、Mermaid 功能或 CI 修复。

## 事务要求

沿用 `markdown_table_source_plan()` 的“准备转换 → 源码公式对齐 → 模型粘贴 → 换行恢复 → 重新验证 → 生成编辑计划”顺序。全部准备和命令可用性查询均不修改文档。转换加粘贴提交一项历史事务；一次撤销恢复原 Markdown 表格和完整选区，一次重做恢复转换结果及合并格所有权。成功编辑正常清除旧重做分支；被拒绝的操作不得清除它。

## 固定样本与人工验收

从仓库根目录准备一个尚不存在的隔离目录：

```sh
python3 tools/prepare-group4-paste-checks.py artifacts/group4-table-math-current
```

脚本仅准备文件，不启动应用，不执行任何验收。manifest 升为版本 2，生成 36 份 LF/CRLF、无 BOM/有 BOM 样本：`math-target` 和新增 `math-mixed-target` 为成功预期；`math-invalid-target`、脚注和跨行组为拒绝预期。所有状态初始均为 `not_run`。manifest 中的成功预期适用于光标、正反向单选区或合法表格矩形，不适用于任意多选区。

第一批 [粘贴原子性记录](mac-group4-paste-atomicity.md) 保留为历史记录，其中“普通公式应拒绝”和原样本数量已经由本批源码、脚本和本文取代；不要用旧断言判断新功能。

人工操作使用隔离副本，不直接修改仓库 fixture：

1. 在 `math-target`、`math-mixed-target` 的 `input.md` 中按第一批流程建立两项独立输入历史，然后撤销后一项，保留可用的重做分支。记录当前全文和选区。
2. 打开 `merged-payload.md`，通过应用原生表格选择和复制整份合并内容；在目标文档“目标中文🙂”所在单元格粘贴。不能将 HTML 源码作为普通文本输入来替代原生剪贴板测试。
3. 确认转换成功、合并格结构正确；未选中的公式仍以公式显示。混排样本的公式源码按顺序为 `h`、`x^2`、`a+b`、`z`，强调、链接和中文/emoji 邻接不能丢失。
4. 一次撤销恢复原 Markdown 表格、方向/端点/主选区及矩形所有权；一次重做恢复转换后状态。再回退到更早的输入事务检查分组没有串联。
5. 点击每个公式左右两侧，在正文两端输入；在中间插入 `<`、`&` 和反斜杠；删除实体、删除最后一字、重新输入、完整选中删除及撤销。不能在标签外插入正文、跨格错位或留下半个实体。
6. 保存、完全退出应用、重新打开，核对公式语义和继续编辑能力、文件 BOM/换行及表格外文本。浅色和深色分别操作并检查截图。
7. 对 `math-invalid-target`、`footnote-target`、`cross-groups`、`cross-head-body` 重复拒绝操作，检查全文/选区/修订/历史不变，并立即重做先前输入，证明原重做分支仍可用。再执行合法粘贴证明拒绝没有污染下一次操作。
