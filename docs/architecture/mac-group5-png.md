更新：2026-09-29。依据第五组v1.2；测试资料留本机，非阻塞细节按用户反馈处理。

## 当前结论

**5D通过并正式结项：I01—I03及PNG适用的X01—X08已逐项核对完成。** 至此HTML、PDF、系统打印、PNG四个批次的格式专项与各自公共路径均已关闭，24组功能验收在分批证据层面全部具备通过依据；第五组整体仍未结项，下一步进入5E统一构建验收。实体打印仍按5C边界未执行。

真实菜单「文件 → 导出 PNG…」提供320–2048逻辑宽度、1×/2×及浅色/当前正文主题。默认宽度来自阅读设置而非窗口像素，PNG偏好独立保存。整文档先准备资源与完整布局，再离屏绘制；没有滚动截图、PDF截图拼接、浏览器生产引擎或新Markdown解析器。

## 实现与固定预算

复用已有整文档语义、CoreText文字整形、静态公式/图表及绘制命令；以连续画布长度和预算决定分段，不沿用PDF纸张高度。按完整文字行及表格跨行合并组切分，PNG分段不重复表头/页码。CoreGraphics创建单段位图，ImageIO编码；一段完成即释放位图，不持有整组位图队列。

| 约束 | 首批实现值 |
| --- | --- |
| 逻辑宽度、倍率 | 320–2048；1×或2× |
| 单段位图 | 最多16 Mi像素，单边最多32768 |
| 整组输出 | 最多128 Mi像素、64段、256 MiB编码字节 |
| 布局命令 | PNG最多200000项保留绘制命令 |
| 公共限制 | 继承正文8 MiB、单资源32 MiB、资源/SVG预算、同时2任务和准备阶段300秒 |

上述值在边界测试前已固定，没有因为失败提高限额。单图在预算内输出选择的PNG文件；超限时先显示分段数量和目录，用户确认后才编码发布。分段写入新的「名称-images」目录，文件从part-001.png顺序编号，不替换原先选择的旧PNG，不覆盖或合并已有目录。每段在同父目录的任务临时目录中写完并同步，整组成功后通过macOS排他重命名发布；目标临时出现，包含空目录，均不能被覆盖。

## 结项补验与进入 5E
