## 范围与完成条件

P1 继续覆盖主题与结构化排版、表格/嵌套容器编辑，以及这些能力在原生窗口中的交互和保存。原规划的 M4 公式/图表/导出和 P4/M5 性能预算仍保留各自阶段，不因本次改变而完成或取消。

不再要求：Typora 完整 72 场景参考矩阵、相同换行/行数、外观边界差 ≤1pt、专门安排真实 1× 设备。现有截图和原始差图继续保留，作为排查截断、错位、异常间距和回归的工具。未采集的场景不标记通过，也不再因数量不足单独阻塞 P1。

仍然要求：绘制、光标、命中和输入法使用一致几何；无文本遮挡、错误截断、异常空白或编辑跳动；未修改源码不被格式化；真实中文输入、鼠标与保存结果正确。内部几何测试阈值不因取消外观复制而放宽。

## 最后一轮真实操作

使用测试文档副本，记录应用身份、输入源和结果。以下结果当前均为待验证。

1. 正文末尾切换系统拼音，输入 `zhongwen` 并选出“中文”。候选框应跟随光标，提交一次，按一次撤销撤回整次提交，重做恢复“中文”。另起一次组词按 Escape，取消文字不应留在正文，既有撤销仍可用。
2. 在窄窗口使正文换行，滚动后点击行中再组词。输入应落在点击位置，候选框不应跳到窗口角落或错误段落；扩大窗口后继续输入，选区与光标不应脱离正文。
3. 在根表格与引用内表格分别点击单元格，输入中文及 emoji，Tab/Shift-Tab 往返；最后一格 Tab 追加行。连续撤销再重做，检查内容、行数与落点。
4. 用鼠标拖动列分隔线使单元格换行，再立即点击文字并编辑；跨格拖选、复制、粘贴到另一格，检查选区与最终内容。改变缩放后重复一次。
5. 保存、关闭、重开测试副本，核对编辑内容与源码。没有编辑的部分保持原字节；取消的组词没有落盘。任何失败记录实际按键、位置、期望与结果，不以“无崩溃”代替通过。
