## 采用的路线

CoreText/CTTypesetter/CTLine 负责字体、整形、度量和行内布局；CoreGraphics PDF context 负责 PDF 编码、页面与链接；NSImage 通过公开接口向非屏幕 Quartz context 绘制已冻结、安全校验后的 SVG。没有私有 CoreSVG API，没有窗口截图、Metal纹理捕获或整页图片替代正文。

Rust 复用 5A 的整文档语义输出，使用已有 HtmlFragment/HtmlTableGrid 将已解析且惰性的内部结构转成段落、样式运行、资源和完整合并组。这里没有浏览器 HTML 导入，不重新解析 Markdown 或重建脚注/目录编号权威。原生代码只接收已解析流程数据，补纸张、按行分页、表头重复与完整跨行合并组规则。

继续复用 5A 的任务和原子发布，配置显式区分 `exportFormat: pdf`。内部旧 `HtmlJob`/C符号名称保留 ABI；未新增第二套可变文档或文件覆盖机制。转换在工作线程中；原生保存、配置、进度、取消与告警仍由主线程控制。

### 有界选型的实际范围

原生探针实际生成 6 页 PDF，检查普通中文/英文、混合字体、emoji、4 个 SVG 和 PNG。在独立结构检查中，4 个 SVG 页分别有 8/8/21/19 条路径且无位图；emoji 为局部图像。这证明本批所需样本可沿公开系统路线输出，不代表任意 SVG 自动无损转换。

Rust 候选只完成版本/接口/归属核对：krilla 0.8.2、krilla-svg 0.8.1，固定源码 commit `3ffdf0588cf98050aad6edba51ca70162e1fb5b5`，原始包与根 LICENSE/NOTICE 的校验保留在 r01/third-party。NOTICE 中 resvg/MPL 来源仍需要文件级核对；未复制其代码，未将这些库加入产品，**也没有运行 Rust 候选生成 PDF，不能称为双后端性能对比**。按 v1.2 3.3 已有公开系统能力满足当前阶段时，不为凑对照重做另一条文字后端。后续出现真实缺口再针对该缺口评估，不预建多后端框架。

新增直接依赖仅为已锁定 serde_json 1.0.151 的复用边，Cargo.lock 无新增 package/version。补充保存保守非 dev 闭包的 15 个包、28 份原始许可文本，连同清单/说明共 30 份文件，实际随包且逐字节一致。其余归属边界见 `mac-group5-dependency-decisions.md`，不把它当作全发行/字体许可放行。

## 首批实现范围

原生保存面板提供 A4/Letter、横纵方向、18–144 pt 页边距和页码开关，默认 A4 纵向、44 pt、显示页码。PDF固定浅色纸张，导出设置与编辑偏好分别保存；未命名文档可选择相对图片基准目录。

已接入正文、标题、嵌套列表、代码、现有行内样式、公式/七类图表、图片、有限 HTML 表格/居中、目录、展开 details 和混合文末注。PDF保留外链和内部跳转/回链；正文按系统字形整形结果换行，图片/图表整体放置，合并表格沿完整跨行合并组分页并重复表头。

新增公开边界：最多1000页；图形若需缩小至原布局25%以下则要求调整纸张/页边距；表格平均列宽不足24pt时要求调整方向；完整合并组放不进一页时明确失败，不截断。流程序列化及PDF输出最多256MiB，继续继承正文/单资源/资源总量/复杂度/两个并发任务/准备300秒预算。**这些为实现常量，不是本轮已完成全部边界签收。** 暂未提供自定义字体或出版级字距/页眉页脚；后续只补既定支持范围，不扩大为任意CSS排版。

## 发现与修复，失败保留

有限HTML的居中对齐原先只从align属性读取，遗漏了内部writer输出的text-align；补齐有限声明映射，并保留单边图片宽/高与百分比尺寸。直接tr兄弟行及单元格多个段落亦通过已有网格正确映射，未另造表格语义。

逐页查看发现 `~~删除~~` 被共用整文档writer输出为字面字符；新增PDF样式回归先失败，确认后启用comrak已有删除线选项，只作用于整文档路径，并补HTML断言。最终r06两条链路已回归，PDF6×局部确实有删除线。旧5A截图和HTML哈希不包含该修复，不用旧“通过”记录否认这项遗漏。

开发期原生API拼写/类型推导编译错误已修正。r03的图片百分比测试曾使用源语言未支持的CSS写法，修正为已有`width="50%"`语法，并增加正常夹具零告警前置断言；不是用占位放宽产品要求。r04实窗失败点到覆盖提示后方的保存面板取消按钮，改为顶层Escape和等待状态后r05通过，最终r06再次通过；原始失败不删除。

独立长段落检查首版把页码混入跨页词组计数，得到198而非200；保留原始文字和失败报告，只在几何区域及9pt字体验证页码后单独计算正文，恢复200。没有改写PDF或删除任意数字，也不由此宣称所有阅读器跨页全文复制顺序完全一致。生成外部证据摘要时一次版本属性查询失败，改为读取已安装包元数据，不影响产物检查。

此前通用菜单后的拼音共同现象仍保留为 observed_not_fixed；本轮没有修改通用输入法或声明该现象消失。只对PDF原生任务证明拒绝组字时不擅自提交/取消。
