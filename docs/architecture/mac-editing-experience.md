# Mac 核心编辑体验（第二组）

> 2026-09-19 清理更新：原始测试截图、临时应用和详细日志已按用户要求删除，仅保留顶层摘要。下文原始证据路径属于历史记录。后续任务以 [统一产品规划](mac-product-roadmap.md) 为准。

范围：真实系统拼音提交与取消、候选框定位、鼠标跨块拖选、表格拖选和列宽调整、键盘焦点、连续撤销重做。编辑后保存并重开核对源码；未操作区域保持原字节。沿用 macOS 26+ / arm64、AppKit + Rust + CoreText + Metal；本轮不继续性能微调。

- [x] 最终构建：绑定应用身份的原生自检与浅深色真实窗口回归。

## 自动化方法与限制

`artifacts/` 是本地生成的验收证据目录，已由 Git 忽略；下文引用的原始截图、日志、隔离测试应用与哈希索引不随源码提交。验证脚本和固定语料随仓库提交，可在具备权限的 Mac 上重新生成证据。

`tools/native-event-driver.swift` 从独立进程通过 CGEvent 发送键盘和鼠标事件，通过系统 AX 读取源码、选区及焦点。只有显式指定的隔离 Yu 测试应用位于前台时才允许发送事件；使用私有文档和独立 bundle ID，避免修改用户文档/最近记录。系统输入法测试发送硬件键码，不能用直接调用 `setMarkedText` 或 Unicode 注入冒充拼音输入。

截图记录真实系统候选窗口。CGEvent 驱动的实际系统输入链路与人工物理键盘操作分别描述；不声称已完成人工验收。macOS 26、VoiceOver 和 OS 注销恢复仍是独立待验收范围。

## 2026-09-19 扩展实现与证据

本轮修复了查找框焦点之外的三个实际问题：编辑菜单动作及启用判断错误地使用正文状态；非焦点正文通过 `performKeyEquivalent` 截获 ⌘Z；删除最后一个预编辑字符后残留空的 Rust composition，阻挡鼠标与撤销。另允许只有预编辑的干净文档执行显式保存，并增加原生缩放菜单及窗口缩放比例归档。

`f6dd437f…` 的 `native-roundtrip-13/results.json` 完整通过十组外部事件检查：系统拼音/候选、查找剪贴板与焦点、跨段落/Shift 鼠标选择、根/引用表格、矩形复制粘贴与扩行、连续撤销重做、列宽拖动/取消/立即编辑、原生缩放、窄窗口滚动后候选定位、精确 BOM/CRLF 保存。`native-dark-15/` 的扩展深色流程通过至保存，包含根表格 emoji/新增行、组合字符与 emoji 逐字素删除；退出重开检查未完成（工具在应用已正常退出后尝试发送 key-up，被自己的前台保护拒绝）。不得把该轮整体标记通过。

验证工具现已修复修饰键继承问题：批量按键显式清除 flags，快捷键 key-up 释放修饰键；应用退出后的 key-up 只投递原 PID，不发送给新的前台应用。输入源准备显式经历 ABC→拼音并等待通知。早期失败与日志全部保留；不能将工具误触发命令产生的空窗口当作编辑器丢失文档。

列宽使用 `tools/measure-native-rules.swift` 独立测量 PNG 中的三条竖线，验证实际位移与取消回退；同时核对 `.yucolumns` 比例记录，避免依赖固定的滚动条占宽假设。隔离测试专用输入日志绑定 bundle ID 和环境开关，生产默认关闭。

`native-light-16/` 已验证双击英文、整词拖选及三击选段，但三击后后续段落下移 26pt，使后续 emoji 点击落到分隔行。Rust 新测试 `selecting_through_a_separator_does_not_insert_a_caret_paragraph` 在修复前失败（25.6 对 0），修复后普通 CRLF/引用段落的正反选区都通过，真正空行光标仍保留行高。证据 `selection-separator-red.log` / `selection-separator-green.log`。

当时剩余工作（现已完成，见最终验收）：当前构建完整浅深色外部事件、双击 Unicode、125% 表格交互、独立进程重开、14 原生检查/浅深色窗口回归，以及新增缩放/选段相关回归。第一组文件流程需在最终构建复验。全部结果绑定最终构建后，才能标记第二组完成。
