# Mac 文档与数据安全

> 2026-09-19 清理更新：原始测试截图、临时应用和详细日志已按用户要求删除，仅保留顶层摘要。下文原始证据路径属于历史记录。后续任务以 [统一产品规划](mac-product-roadmap.md) 为准。

目标：完成当前规划第一组（新建、另存为、最近文档、自动保存、崩溃恢复，以及多窗口保存/关闭与外部修改冲突）。性能微调已由用户暂停优先推进；不改变之前测量的通过/失败事实。

## 功能契约

- 新建使用独立 Rust 会话和私有草稿身份；不提前创建用户文档。标题为“未命名”，首次保存使用原生面板；取消不丢内容。
- 另存为保留源码字节、BOM、选区和撤销历史，不修改原文件。覆盖须经原生面板确认；拒绝覆盖另一个 Yu 窗口正在编辑的目标。成功后更新文件身份、标题、目录监视、相对资源基址和最近文档。
- 最近文档使用 NSDocumentController 的持久记录，提供打开和清除菜单；路径别名去重，多窗口菜单动作跟随当前窗口。
- 自动保存默认开启，可在文件菜单关闭。编辑后 1 秒合并保存，持续编辑最多 5 秒做一次检查点。关闭自动保存仍保留恢复副本。自动保存不提交 IME 预编辑、不覆盖外部修改或被删除的文件；失败保持内容与脏状态并明确显示。
- 恢复信封保存原磁盘指纹、实际存储路径、BOM 和已提交源码。恢复本身不写目标，恢复内容须手动确认保存后才能恢复自动保存；发现损坏记录保留文件并报告，不能静默删除。
- 启动及文件菜单可发现恢复副本，支持恢复、丢弃、稍后。新建文档和原文件已删除的文档也可恢复。丢弃只删除恢复记录；不修改磁盘原文。
- 单窗口关闭提供保存/不保存/取消；应用退出先收集所有窗口决策，再清理恢复记录。任一窗口取消或保存失败，所有暂定关闭状态回滚，先前的“不保存”不提前删除恢复内容。
- 保存继续由 Rust 原子写入，未编辑 Markdown 不重新格式化；失败不伪装成成功。新目标或外部版本在暂存写入期间变化时，替换前再次检查。

## 2026-09-18 最终验收

最终 release：`b10e43276bbc5dccaace33236fe66e5e523f699ba1f136400c030e55a26eae9e`，arm64，部署目标 macOS 26.0，本机 macOS 27 / Xcode 27 / SDK 27。FFI 更新后完成干净构建；最终附加关闭场景和最近文档容量测试后重新构建。1,043 Rust 测试通过、4 忽略；依赖、FFI、坐标门禁通过；14 项原生检查及浅深色实际窗口套件通过。

`accepted-check/results.json` 覆盖浅深色文件流程、两次跨进程最近文档读取，以及 SIGKILL 后的命名/未命名/已删除文件恢复。测试副本使用独立 bundle ID 和私有文件，机器代码段与生产构建一致，避免污染用户最近文档与设置。原生面板决策由测试注入，不声称人工面板或真实中文输入已验收。

额外覆盖：选择“稍后恢复”后打开同一路径不会创建覆盖旧副本的新会话；另存为拒绝占用该恢复目标；损坏副本经用户选择后原字节归档再打开磁盘原文。关闭窗口覆盖取消、保存、首次保存取消、外部冲突保存副本；应用退出取消回滚所有暂定关闭状态。

扩展关闭测试一度让早期目标超出系统最近文档容量，跨进程断言因此失败。已改为检查最新保存目标，最终完整重跑通过；失败记录保留在 `close-actions-check/`，未用部分通过替代最终验收。

恢复目录损坏不会静默丢弃可读记录，自动保存不提交输入法预编辑，手动保存失败保持原身份及内容。恢复只保证最后成功检查点；macOS 26、真实输入法、VoiceOver、系统注销/重启恢复与发行公证仍须后续独立验收。
