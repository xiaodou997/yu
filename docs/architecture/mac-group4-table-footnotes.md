## 表示与关系

保存的不是编号，而是保留原标签的有限 HTML 源码叶子：

```html
<span data-yu-footnote="reference">[^note]</span>
```

定义仍在原文档的 `[^note]: ...` 中，表格外字节不因转换而被改写、搬移或复制。`source` 指向整个元素，`content` 指向正文，均为规范文档 UTF-8 字节范围。HTML 实体只在读取正文时解码一次；解码后的字符串偏移不被冒充为原文偏移。

转换器给出候选引用，编辑器再逐单元格核对原语法树引用数量、标签与唯一目标定义。总数相同但引用移到别的单元格、交换标签、缺少引用或无法解析定义，都会拒绝，不能把脚注降级为普通上标。

HTML 与 Markdown 引用合并到同一 `FootnoteIndex`，以正文出现顺序编号。重复引用共用定义，定义标记回链到首个正文引用；已使用定义内的引用继续沿用有界队列遍历，循环不会递归失控。现有 FFI 引用跳转查询消费该索引，不另造 HTML 锚点编号系统。

表格投影显示当前索引生成的上标数字；活动引用显示可编辑 `[^标签]` 正文。表格内外增删引用会重算编号并使受影响的装饰缓存失效，表格源码不必重写。折叠 details 的正文不显示脚注数字，但不改变文档的语义引用顺序。

## 编辑与粘贴边界

- 合法引用、唯一且位于表格外的定义，支持转换；公式、中文/emoji、强调、链接与重复引用可混排。
- 转换前缺失定义、重复定义、错误属性、自闭合、嵌套标签/注释、无效引用正文等安全拒绝。转换后用户修改定义造成缺失或歧义时，保留原始引用、显示诊断、禁用错误跳转；修复定义后重新绑定。
- 整体选择引用删除会连同其包装标签删除一次，不删除外部定义或其他重复引用。完整替换引用正文可以切换标签；将正文编辑为非法的中间状态时保留源码并回退源码展示，修复后恢复原生表示。
- 原生表格剪贴板保留标签；传入的引用只能绑定目标文档已有的唯一同标签定义。外来定义导入、冲突重命名及跨文档定义搬迁不在本批。`PasteHtmlTableSource` 与 `PasteHtmlTableGrid` 使用相同目标校验。
- 字面实体拼写标签（如 Markdown `[^a&amp;b]`）存在当前解析器与转换器分歧，本批保持安全拒绝，不声称所有合法标签均已支持。已有 HTML `[^a&amp;amp;b]` 正确解码一次，仍与 `[^a&amp;b]` 表示的另一标签区分。
- 任意多光标不被自动推断为表格矩形。跨 `<thead>/<tbody>`、多个 `<tbody>` 的原有限制不变，不拆散传入合并格来冒充支持。

## 事务与回归演进

## 52 份隔离人工样本

从仓库根目录运行，输出目录必须尚不存在：

```sh
python3 tools/prepare-group4-paste-checks.py artifacts/group4-table-footnotes-current
```

manifest 版本 3，共 52 份：13 场景 × LF/CRLF × 无 BOM/有 BOM。24 份为拒绝预期；其余为成功预期。每项 `status` 和总 `native_test_status` 初始都是 `not_run`。脚本只准备文件，不启动应用或执行验收。

`footnote-target` 为最小成功场景；`footnote-mixed-target` 混排公式与三个外部定义，全文引用编号应为 `[1, 2, 2, 3, 2]`。`footnote-missing-target`、`footnote-duplicate-target` 和 `footnote-invalid-target` 为拒绝场景。已有公式成功样本、非法公式与跨行组拒绝样本继续保留。

人工验收使用隔离副本，不编辑仓库基准：

1. 打开目标 `input.md`，建立两项独立输入历史，撤销后一项，保留可重做分支。记录全文和选区。
2. 在应用内复制 `merged-payload.md` 的合并表格内容，粘贴到“目标中文🙂”所在格。不要以输入 HTML 源码替代真实原生剪贴板操作。
3. 确认合并格与未选中引用正确，脚注编号为当前全文顺序；Command-click 每个数字左右两侧跳到正确外部定义，定义标记回链到首个正文引用。混排公式仍为公式。
4. 一次撤销/重做核对完整源码和选区；继续回放更早输入验证分组。修改外部定义、增删更早引用，检查编号与缓存立即更新；多次同标签引用不得绑定到其他定义。
5. 完整修改引用正文、删除整个引用、撤销、同文档复制粘贴；检查定义不被误删或复制。人为造成缺失/重复定义后应有诊断且不能跳错，修复后恢复。
6. 对拒绝场景重复操作，核对全文、选区和历史不变，立即重做先前输入证明分支仍在。合法粘贴应能继续执行。
7. 保存、完全退出应用、重新打开，核对规范源码、BOM/换行、脚注语义、跳转和继续编辑。浅色与深色分别操作、复核截图，记录应用/helper 哈希和实际提交 SHA。
