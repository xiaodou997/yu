## 复用与许可

先盘点已有封装和锁定依赖；公开系统 API 与成熟开源按职责选择，不要求全部原生或全部 Rust，也不要求原生彻底失败后才准用 Rust 库。只补 Yu 特有规则，不自造 Markdown 解析器、PDF 编码器、完整 SVG 引擎，不另造通用多后端框架。

5A 复用 comrak、Yu 公式/脚注/TOC/有限 HTML 模型、原 helper、NSSavePanel、ImageIO。文档导出与剪贴板 unsafe HTML 合同隔离。5B 优先检查 CoreGraphics；可同时有限比较 krilla/krilla-svg，选定版本 NOTICE 中的 MPL 来源先核对。resvg/usvg 仅按实际资源缺口评估；不以栅格化冒充 PDF 矢量。归档 svg2pdf 不作为新依赖首选。

直接依赖固定版本/features；复制或改编记录仓库/commit/文件/版权/本地修改，保留 LICENSE/COPYING/NOTICE。默认双许可不覆盖文件级例外、传递依赖、素材和字体；不分发系统/用户字体。comrak 上游规范测试材料不得当作 BSD 全目录复制，不向其自动提交 AI 生成 PR。许可核对随引入，不拖到发布时补。具体决策和未完成检查见依赖决策表。

## 不变产品合同

确认格式与目标后捕获已提交版本，可包含未保存编辑；存在组字则要求用户完成/取消，导出不得代办。任务启动后可继续编辑，产物不混入后续版本；日期/主题和本地资源按任务固定。编辑现场、完整选区、撤销/重做、脏状态、磁盘原文及原图片不得被导出改变。

HTML 单文件内嵌 CSS、本地图片、静态公式图表；默认无网络，无脚本/CDN/远程字体。安全 HTML 默认展开 details，脚注全文编号/文末定义/重复回链，TOC 稳定锚点；front matter 仅明确支持的安全字段。不支持/不安全内容安全转义且可读，不能静默删除。缺失、无权限、远程、错误资源须明确提示，用户同意后才 completed_with_warnings；有效内容的导出器缺陷不准自动降级正常通过。

目标目录临时文件完整写出并校验后原子提交；覆盖须确认，失败保留旧目标。拒绝源文档/引用图片及路径、符号链接、硬链接别名。取消只清理本任务资源。原生菜单只列已实现能力，阶段进度不用虚假百分比。HTML/PNG 默认浅色，可选当前正文主题；屏幕缩放/滚动/专注模式不改变输出。

## 证据

复用 tools/run_acceptance.py，不创建另一套全局执行器。每组分开记录 core/native/real_window/cold_reopen/visual；文件结构和字节检查标明其证据类型。not_run/partial/passed/failed/blocked 不混用。completed_with_warnings 是产品结果，不是自动验收通过。

固定语料涵盖普通中英文/emoji、综合文档、长代码/段落、合并表格、多公式编号、七类图表、混合脚注、TOC/details/front matter、本地/中文路径/缺失/远程图片、不安全 HTML/URL/SVG。LF 和 BOM+CRLF 各有代表；不穷举主题/编码/格式/手势的笛卡尔积。相关批次执行连续导出 10 次、可取消格式 3 次取消重试、两个文档交替；实体打印未授权不执行。
