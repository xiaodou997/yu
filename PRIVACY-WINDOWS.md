# Yu for Windows Privacy Policy / Yu Windows 隐私政策

Last updated: October 1, 2026 / 最后更新：2026 年 10 月 1 日

## English

This policy describes the current Yu Windows desktop application. Yu is a local
Markdown editor. It does not require an account and does not collect, transmit,
or sell personal data, document contents, usage analytics, or crash reports.

Yu reads the documents you open and local images referenced by those documents.
Edits remain in memory until you save them to the location you choose. Formula
and Mermaid rendering runs in a local companion process. Yu does not upload
documents to a rendering service or download remote document images.

Copy and paste use the Windows clipboard. Windows input methods, file dialogs,
and accessibility tools are provided by your operating system and may access
the text or file information needed to perform the actions you request. Their
own settings and privacy policies apply.

If you contact us through GitHub Issues, GitHub handles the information you
submit under its own privacy policy. Microsoft Store installation, updates,
and store diagnostics are handled by Microsoft under its policies.

We will update this policy and the Store privacy declarations before shipping
changes to these data practices.

Questions: [Yu support on GitHub](https://github.com/xiaodou997/yu/issues).

## 简体中文

本政策适用于当前 Yu Windows 桌面应用。Yu 是本地 Markdown 编辑器，无需账户，
不收集、传输或出售个人数据、文档内容、使用分析数据或崩溃报告。

Yu 读取你打开的文档及文档引用的本地图片。编辑内容保留在内存中，直到你保存到
选择的位置。公式与 Mermaid 渲染在本地辅助进程中完成，Yu 不会把文档上传至渲染
服务，也不会下载文档中的远程图片。

复制和粘贴使用 Windows 剪贴板。输入法、文件对话框和辅助技术由操作系统提供，
可能访问完成你所请求操作所需的文本或文件信息，适用其自身设置和隐私政策。

通过 GitHub Issues 联系我们时，你提交的信息由 GitHub 按其隐私政策处理。
Microsoft Store 的安装、更新及商店诊断由 Microsoft 按其政策处理。

如上述数据处理方式发生变化，我们会在发布前更新本政策和商店隐私声明。

问题反馈：[Yu GitHub 支持页面](https://github.com/xiaodou997/yu/issues)。
