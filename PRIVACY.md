# Yu Privacy Policy / Yu 隐私政策

Last updated: September 29, 2026 / 最后更新：2026 年 9 月 29 日

## English

Yu is a local Markdown editor. The Mac app does not require an account and does
not collect, transmit, or sell personal data, document contents, usage
analytics, or crash reports.

Documents and exported files stay in the locations you choose. Yu may keep
local settings, recent-file information, file-access bookmarks, and recovery
copies on your Mac so that editing and reopening documents work. You can remove
these local records by deleting Yu's data from your macOS user account.

Opening a web link in a document hands that link to your default browser.
If you choose to contact us through GitHub Issues, the information you submit
is handled by GitHub under its own privacy policy.

This policy describes the Mac App Store version of Yu. If its data practices
change, we will update this page and the App Store privacy answers before
shipping the changed version.

Questions: [Yu support on GitHub](https://github.com/xiaodou997/yu/issues).

## 简体中文

Yu 是本地 Markdown 编辑器。Mac 应用无需账户，不收集、传输或出售个人数据、
文档内容、使用分析数据或崩溃报告。

文档和导出文件保存在你选择的位置。为支持编辑与重新打开文档，Yu 可能在 Mac 本地
保存设置、最近文件信息、文件访问书签和恢复副本。你可以从 macOS 用户账户中删除
Yu 的本地数据。

在文档中打开网页链接时，Yu 会将链接交给默认浏览器。如果你通过 GitHub Issues
联系我们，你提交的信息受 GitHub 自己的隐私政策约束。

本政策适用于 Yu 的 Mac App Store 版本。如果数据处理方式发生变化，我们会在发布
相应版本前更新本页面和 App Store 隐私声明。

问题反馈：[Yu GitHub 支持页面](https://github.com/xiaodou997/yu/issues)。
