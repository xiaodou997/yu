Yu for Windows x64 - portable edition

Extract the entire ZIP to a normal folder, then open Yu.exe.
Do not run the application inside the ZIP preview.
Keep yu-document-renderer.exe beside Yu.exe; it renders formulas and Mermaid.
Keep the Licenses folder with this distribution.

This edition needs no installer, Microsoft Store account, developer certificate,
administrator access, or Developer Mode. It does not register file associations
or install an automatic updater. Use File > Open or pass a Markdown path to Yu.exe.
To update, close Yu and extract the new ZIP into a separate folder.
To remove the app, close Yu and delete its extracted folder; keep your documents.

The executables are not Authenticode-signed. Windows may show an unrecognized-app
or unknown-publisher warning. Some Smart App Control or managed-device policies
may prevent running this unsigned edition. This package does not modify security
settings. Obtain releases from the official repository and compare SHA256SUMS.txt.
The checksum detects file changes; it is not a publisher signature.

Target: Windows x64, Windows 10 build 19041 or later.
Local native acceptance was performed on Windows 11 24H2 build 26100.
Windows 10 and clean-machine compatibility remain to be verified.
