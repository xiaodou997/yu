Yu for Windows x64 - GitHub installer edition

The installer places Yu.exe, its local formula/Mermaid companion, and license
notices in the current user's application directory. It creates Start Menu
entries and an optional desktop shortcut. It does not require administrator
rights, a Microsoft Store account, a certificate, or Developer Mode.

Open Yu from the Start Menu. Use File > Open to select a Markdown document.
Keep yu-document-renderer.exe beside Yu.exe.
Close Yu before running a newer installer to update it.
Uninstall through Windows Settings > Apps or the Yu uninstall shortcut.
Your Markdown documents remain at the locations you choose.

This release is not Authenticode-signed. Windows may show an unrecognized-app or
unknown-publisher warning; Smart App Control or managed policies may block it.
The installer does not modify Windows security settings or default file handlers.
Obtain releases from https://github.com/xiaodou997/yu/releases and compare the
provided SHA256SUMS.txt. A checksum is not a publisher signature.
