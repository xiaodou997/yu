# Windows 产品壳验收

这个文件用于检查侧栏、状态栏和正文之间的导航。

## 文件面板

文件页应列出当前文件所在目录的 Markdown 文件。

单击选择文件，双击或按 Enter 打开。未保存的修改应先出现保存确认。

## **大纲** 与 `标题`

大纲应显示标题正文，隐藏星号、反引号和井号，并保留层级缩进。

### 子标题：中文 / 日本語 / 한국어

选择大纲条目后，正文光标应移动到对应标题。

## 文内搜索

测试行一：中文😀 alpha。

测试行二：before 中文😀 after。

搜索使用区分大小写的字面匹配。选择结果应定位并选中正文中的匹配文字。

## 键盘与焦点

Ctrl+F 打开搜索并聚焦输入框。Enter 跳到结果，Escape 返回正文。

在搜索输入框输入、删除或撤销查询，不应修改正文或正文的撤销历史。

隐藏侧栏后，键盘输入应回到正文。

## DPI 与外观

在当前缩放比例及后续 100%、125%、150% 下检查字体、行高和内边距。

浅色和深色模式下，导航的选中、悬停及焦点状态都应清楚可辨。
